# Diagrams

本目录存界面标注图的输入与产物，以及外部导入的位图。流程图、架构图、状态图用 Mermaid 写在 `prd.md` 与 `tasks.md` 正文里，不放这里。

| 文件 | 内容 | 谁产出 |
| --- | --- | --- |
| `<截图名>.json` | 截图清单：页面、角色、状态、触发与裁剪 | 手写 |
| `<截图名>.marks.json` | 标注清单：按元素文案挑选，写说明与步骤 | 手写 |
| `<截图名>.png` 与 `<截图名>.md` | 原型截图与来源说明 | `capture.mjs` |
| `_coords.json` 与 `_coords.md` | 元素坐标、原型指纹与来源说明 | `capture.mjs`，不要手改 |
| 其它位图与同名 `.md` | 外部导入的截图或素材，说明写清来源、获取日期、用途 | 手写 |

原型改动后先重跑 `capture.mjs` 再重跑 `annotate.mjs`，只跑后者会拿旧坐标画新说明。
